# MirrorForce × Qwen 在线动作蒸馏实验报告

> 本文件是报告模板，不包含已取得的模型效果。所有“待运行／待填写”只能由可追溯的实际产物替换。没有文件、日志、模型或对应命令证据的结果，保持“未验证”。

## 1. 研究问题与贡献边界

研究问题：在冻结专业游戏教师的条件下，对学生实际访问状态进行动作分布监督，是否比固定离线监督更有效？

上游提供：MirrorForce 游戏引擎集成、原策略模型、发布检查点、卡牌资源及既有对局协议。上游来源：<https://github.com/tommy85/MirrorForce>。

本项目新增：客户端可见输入序列化、Qwen 标准语言模型动作 token 输出、SFT/离线KD/在线KD、数据和动作契约、训练恢复、预算编排及评测。

任务范围：闪刀姬镜像。动作级在线蒸馏不等同于已完成奖励RL；本实验不证明通用游戏王能力、自然语言推理能力或商业落地收益。

## 9. 失败分析与结论

至少选择以下类型中的真实案例，附game_id/decision_id及输入输出：

- 学生与教师分歧后获胜或失利的局面。
- 教师监督本身可能失准的局面。
- 输入遗漏、语义映射或历史截断造成的失败。
- 菜单顺序敏感、同名卡位置混淆或多卡子选择失败。

分别讨论：更多数据、数据分布变化、软标签与硬标签、计算预算和信息表达的作用。继续SFT与在线KD同时改变目标和数据，不能单独用该差异归因于在线采样。
